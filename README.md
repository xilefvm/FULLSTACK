- Git
- Según el proyecto: JDK, Node.js, navegador o Docker

## ⚡ Inicio rápido

```bash
git clone https://github.com/xilefvm/FULLSTACK.git
cd FULLSTACK/<nombre-del-proyecto>
```

Cada proyecto incluye su propio README con instalación y ejecución.
