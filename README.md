## ⚡ Inicio rápido

**Requisitos generales**

- 🔧 Git
- ☕ JDK 27 y Maven, para proyectos Java
- 🟢 Node.js, para proyectos con front-end en TypeScript
- 🐳 Docker, si el proyecto lo incluye

**Clonar y entrar**

```bash
git clone https://github.com/xilefvm/FULLSTACK.git
cd FULLSTACK/DataClean
```

Cada proyecto incluye su propio README con instalación, configuración y ejecución.
